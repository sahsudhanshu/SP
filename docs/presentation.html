Problem and approach

A headline is not a risk decision

The gap

  1. 01Reports arrive without the book they affect.
  2. 02A repeated social post can look like a second event.
  3. 03Sentiment does not name the exposed positions.
  4. 04A loss total cannot be challenged without its assumptions.

The approach

RiskPulse keeps severity, evidence, exposure, and loss as separate numbers.

  1. 1Ingest news and social text.
  2. 2Fuse copies into one event.
  3. 3Trace one path per position.
  4. 4Reprice that book under an explicit scenario.

Synthetic issuers, positions, and shocks. Public or synthetic text only.

Implementation

Each module answers a risk question

Is this a new event, or the same report again?
Copy collapse. Distinct text and publisher can add at most a small evidence bonus.
How severe is it?
Impact 1–10 from severity, sentiment, relevance, source type, and exposure. Weights are shown.
How strong is the evidence?
Confidence and recency adjust priority only.
Which positions are in the path?
Issuer match, else sector, else systemic spillover. One path per asset.
What if the shock is stronger?
Same valuation engine. Intensity, impact, rates, and equities are explicit inputs.

Limits and next steps

What this prototype does not claim

Now

  1. Small correlated synthetic set
  2. Dictionary entities
  3. Heuristic confidence
  4. Illustrative shocks
  5. Simplified derivatives, no hedging or netting
  6. One local process

Next, only if labelled and reviewed

  1. Independent labels
  2. Source provenance
  3. Calibrated shocks
  4. Instrument pricing
  5. A risk-team backtest

Decision-support prototype. No market-prediction or regulatory-compliance claim.
